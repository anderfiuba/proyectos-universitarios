# Inventory Management System

Command-line inventory management system developed with Python and PostgreSQL.

The application allows users to manage products stored in a PostgreSQL database through a terminal interface.

## Features

- View all products
- Search products by name
- Add new products
- Update product stock
- Detect low-stock products
- PostgreSQL database persistence
- Input validation
- Parameterized SQL queries

## Technologies

- Python
- PostgreSQL
- Psycopg
- SQL
- Docker
- Git
